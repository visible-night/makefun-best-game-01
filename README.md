Lumen Drift is a neon arena survival game built for make.fun's "Make the best game" bounty. You pilot the Lumen, a lone light-ship, against escalating waves of the swarm: chasing drifters, strafing weavers, splitting hexes, lunging chargers, and every fifth wave, the Warden. Steer with WASD or arrows, aim with the mouse, hold click to fire, dash through danger with Space, and clear the screen with a nova blast (E or right-click). Chain kills to raise your score multiplier, grab shards and hull cells, and see how many waves you can outlast. All art is drawn in code and all sound is synthesized with WebAudio — the game is static files with no network request.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in a desktop browser
```
